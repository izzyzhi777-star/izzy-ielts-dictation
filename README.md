# IZZY IELTS-DICTATION

本小程序用于训练雅思听力中的数字，默认使用 Sonia 英式女声，也可以切换 Ryan、Libby 或男女混播。首次播放新数字或日期时会自动生成并缓存英式神经语音。

## 打开

双击 `启动数字听写.command`，它会自动启动本地服务并打开浏览器。

如果 macOS 提示是否允许运行，请选择“打开”。使用时保持终端窗口开启；按 Control + C 可以关闭服务。

## 四个数字范围

1. **1–100**：基础数字，可顺序或乱序。
2. **100–1,000**：每次打开或重开都会随机抽取 100 个易错数字。
3. **1,000–10,000**：每次随机抽取 100 个易错数字。
4. **1–90 billion**：从全范围中随机抽取 100 个雅思机考常见、易混淆数字，覆盖 hundred、thousand、million、billion。

英文读法不使用 `and`，例如：

- `123` → `one hundred twenty three`
- `1,001` → `one thousand one`
- `13,000,000,000` → `thirteen billion`
- `90,000,000,000` → `ninety billion`

## 日期专项

日期专项包含两个模式：

- **月日英文 → 数字**：100 个雅思高频日期示例。只播报 `the twenty-seventh of June` 这类日期短语，你填写阿拉伯日号 `27`；提交后显示英文拼写 `the twenty-seventh of June` 和完整日期 `Saturday, 27 June`。
- **日期数字**：从 1 号到 31 号播报英文序数，例如 `the twenty-seventh`，填写阿拉伯数字 `27`，并可选顺序或乱序。

右侧“星期发音目录”包含 Monday–Sunday，点击即可分别听发音。日期专项固定使用预生成的 Sonia 英式神经语音，发音流畅自然，不需要临时联网。

## PC / 手机同步

应用使用你自己的 GitHub 私密 Gist 同步数据。Token 只保存在各自设备的浏览器中，不会写进网站源码。

1. 在手机 GitHub 创建一个只勾选 `gist` 权限的 Token。
2. 在手机网站“设置 → PC / 手机数据同步”里粘贴 Token，点击“创建同步空间”。
3. 复制生成的同步码。
4. 在电脑网站中输入同一个 Token 和同步码，点击“连接同步码”。
5. 两台设备会同步自定义词句、听力错词、数字日期错题、练习记录和设置。

Token 不会发送给开发者，也不要公开分享。每台设备需要输入一次 Token。

## 键盘快捷键

- 填写答案时按 `Tab`：立即重播当前数字或日期。
- 按 `Enter`：提交答案；提交后再次按 `Enter` 进入下一题。

## 设置齿轮

- **播报速度**：0.75×、1.0×、1.2×、1.5×
- **播报声音**：Sonia、Ryan、Libby、男女混播
- **提交方式**：手动提交或停止输入约 1 秒后自动提交
- **播报次数**：1–4 次
- **阿拉伯数字顺序**：顺序或乱序；100 以上的范围始终重新随机抽取 100 题

## 我的词句

在“我的词句”中可添加英文单词、词组或句子：

- 自动生成标准中文翻译
- 中文翻译可手动修改
- 可添加个人笔记
- 可按现有速度、播放次数、间隔和手动/自动提交设置练习
- 拼写错误自动进入听力错词本

## 听力错词本与艾宾浩斯

听力错词按以下间隔复习：

`5 分钟 → 30 分钟 → 12 小时 → 1 天 → 2 天 → 4 天 → 7 天 → 15 天 → 30 天`

答错会重置到第一阶段，答对会进入下一阶段；可以复习到期内容，也可以全部复习。

## 随身听

“随身听”支持连续播放数字、月份、日期序数、完整日期和错题：

- 睡眠模式：关闭、5、10、20、30、60 分钟
- 每题重复：1、2、3、5 次
- 播放速度：0.75×、1.0×、1.2×、1.5×
- 播放模式：只念英文或中英对照
- 间隔时间：0.5、1、2、3、5 秒
- 可勾选数字 1–100、100–1,000、1,000–10,000、1–90B、月份、日期序数、完整日期、我的词句、听力错词和数字日期错题

## 单词目录

单词目录分为三类，点击任意条目即可播报：

- 数字 1–100
- 月份 January–December
- 日期序数 the first–the thirty-first

## 错题本

数字和日期答错后都会自动进入“错题本”，可以单独播放、单独重练或按类型集中重练。日期错题会保留原来的练习方式；答对后自动移出。

## 音频缓存

动态生成的神经语音缓存在：

`audio/cache/`

日期、月份、星期和 1–31 号序数音频已经全部用 Sonia 英式神经语音预生成，不需要联网。大数字首次播放时需要联网生成，之后同一数字会直接使用缓存；如果当前神经音色暂时不可用，会自动尝试其他英式神经音色。答案不会上传。
